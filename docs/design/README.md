## Состояние после внедрения

Визуальная миграция первой волны завершена. Следующий Git-коммит, merge и push требуют отдельного разрешения. Светлая тема — отдельный будущий этап; исключённые области и функциональный backlog не становятся частью v1.0 автоматически. Старые описания D0 и поэтапного внедрения сохраняют исторический смысл, а не текущий статус «не начато».

Временные калибровочные материалы, PNG-сравнения, HTML-стенды и проверки остаются во внешнем локальном каталоге checkpoints рядом с проектом. Они не скопированы в репозиторий и не являются обязательными внутренними ссылками этого комплекта.
