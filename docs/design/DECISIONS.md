## Технические ограничения — не незакрытая числовая калибровка

1. **Шрифтовой файл — выполнено I2.** Локальные Noto400/600/700 и OFL.txt поставлены в frontend/src/assets/fonts/noto-sans-v1; alias Tremor Noto Sans v1 изолирован от legacy fallback.
2. **Legacy cascade.** ui.css импортируется Disassembly.tsx, tokens.css импортируется ui.css. App импортирует AssemblyPage, тот — Разбор; импорт CSS не ограничен видимостью одного окна. Глобальная замена существующих переменных затронет исключённый экран.
3. **Select — выполнено I4c.** Основной браузер — Google Chrome на Windows. Шесть обычных Select используют customizable native picker по совместному @supports; без поддержки остаётся native fallback. Четыре modal Select сохраняют системное меню; дальнейшая миграция modal picker и полноценная screen-reader верификация требуют отдельного решения/проверки, не считаются автоматически выполненными.
4. **Badge wrap — выполнено I7.** StatusBadge измеряет longest actual wrapped line с fonts.ready/ResizeObserver; одна прямоугольная подложка, без изменения текста.
5. **Sticky header — выполнено I6f.** Приняты локальные dark-only подложки #080808 Каталога и #202226 нехватки. Прозрачность общего Table v1 не меняется; DataTable/новый DOM не вводились.
6. **Modal Escape — выполнено I8.** Шесть тёмных диалогов не закрываются Escape/backdrop; предусмотренные кнопки, busy-guards и возврат фокуса сохранены, операции/API не менялись. Прежние light callbacks сохранены.
7. **Overlay clipping — реализовано I8–I9/I4c.** ErrorTooltip и Event History используют portal/viewport positioning; обычные customizable Select — browser picker/top layer. Сохранять проверки scroll/resize/focus и не заменять их одним z-index.
8. **Контраст прозрачных слоёв.** Ранее замеренный крайний случай errorbadge поверх selected-hover на полностью белой подложке подWindow≈4.35:1; на текущем изображении проверенный диапазон был выше. Это не разрешение менять палитру. При новом фоне/слоях проверить заново и вынести реальное противоречие, не заявлять универсальнуюWCAG-гарантию для любой подложки.
9. **Регрессии.** check-design-system-visual.mjs сейчас сравнивает только Разбор с demo-design-system; не покрывает остальные окна и не может служить единственным visual gate v1.0. Функциональные scripts/test-*.mjs также не заменяют реальные browser-interaction проверки.

Применимость конкретных вариантов к TREMOR проверяется по локальному коду, а не по общим примерам документации.
