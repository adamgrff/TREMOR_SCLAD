## Числа, которые являются рекомендациями или производными

- Информационные ширины280/200/160/120/232 — стартовые ориентиры, не hard min-width.
- Action-cell72/132/192 — расчёт группы48/108/168 плюс padding24. Реальный состав кнопок важнее одинаковой фиксированной ширины всех таблиц.
- Modal640/960 — uppercaps конкретных образцов, не общий фиксированный width и не два обязательных размера для любого dialog.
- EventHistory≈334 — сумма нормального heading/padding/list; не фиксированная высота. List260 — настоящий верхний предел, уменьшаемый по viewport.
- Видимые размеры после zoom приблизительны из-за дробного округления/DPI; норматив хранится в CSSpx.

## Техническая доступность без самовольного редизайна

Сохранять имеющиеся native/local focus. Не срезать outline overflow-контейнером. У старых исключённых областей не сбрасывать outline/animation/opacity универсальным CSS. Новые layer-механизмы проверяются внутри native dialog; portal не является разрешением потерять тему или наследование токенов.

## Фактические исключения после I1–I12.7

- Основной браузер: Google Chrome на Windows. Для неподдерживаемых браузеров сохраняется простой native fallback без обещания одинакового picker rendering. Шесть обычных Select мигрированы; четыре modal Select сохраняют системное раскрытое меню.
- Sticky-header: локальные dark-only подложки #080808 Каталога и #202226 нехватки; общий Table остаётся прозрачным.
- Window Очереди: padding24×40 при ширине>1100px, локальный padding24 со всех сторон при≤1100px. Не распространять на остальные Window.
- Локальные ширины: Scan Input Приёмки364px; фильтр причины Проблемных376px; Select Архива384/328/352px. Форма Каталога имеет колонку440px при≥1101px для полного placeholder; общий Input не получает ограничения ширины.
- Вкладки Каталога сохраняют собственный underline-паттерн. Сканерный статус, код ячейки и ReceivingScrollProgress сохраняют локальные роли. Legacy-предупреждения Архива и отдельные timeline/outcome accents не перекрашиваются без утверждённой смысловой карты.
- Native Modal удаляется по существующему lifecycle без отдельной exit-анимации; это сохранённое ограничение, не повод вводить таймеры в бизнес-операции.
- Динамическое «ЗАКАЗ №…» в правой области Очереди и Активной — Column Heading24/32/600, не Page Title. Счётчик Page Title применяется только внутри существующей капсулы; новые счётчики не создаются.

## Отложенные задачи — не часть завершённой визуальной миграции

- Светлая тема — отдельный будущий этап. Home/Header/Cells/Разбор и новые Ozon/workflow изменения требуют отдельного разрешения.
- Приёмка: автоматический возврат фокуса после операций, рекомендуемая ячейка и фактическое завершение/экспорт истории за день — отдельные функциональные задачи; placeholder-действия не объявлять реализованными.
- Адаптивное наложение поиска Очереди при801px — сохранённый backlog, вне завершённых desktop-контролей.
- Новая пагинация Каталога/Очереди/Ожидающих/Размещённых и API total/pageCount Истории — отдельное функциональное/API решение. Вложенные составы и журналы не получают правило5 автоматически.
- Новое оформление раскрытых modal Select и дополнительные AT/screen-reader проверки — отдельно; не заменять существующий native Select произвольным combobox.
- Различение saving от общего blocked там, где отдельного признака нет, не добавляется стилями. При новом фоновом изображении повторно проверять контраст прозрачных слоёв.
